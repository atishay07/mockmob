## Concrete counterexamples to cover before any new qualification scope

1. **Prompt/schema origin spelling must agree.** `factoryEvidenceV78.mjs` instructs the model to emit `kind: printed_option_input`; `premiseBindingV78.mjs` and its JSON schema accept `printed_option`. A response following the prompt is rejected. Choose one canonical enum and use it in instructions, schema, validator, and serialized audit records; add a prompt-to-schema contract assertion.

2. **Preserve raw gate failure.** Feed `applyOptionResolutionV78` a valid four-option matrix with `passed:false` and a raw failure reason. It must remain failed and retain that reason. Repeat at `verifyCandidateV78` across source support, numeric, passage, and explanation gates so a later successful matrix/audit cannot turn any raw failure into eligibility.

3. **Keep blind inputs separate and hide proposed answers.** Use one candidate whose key is C and whose explanation explicitly says C. Capture Luna and Gemini request bodies: neither blind input may contain the key, proposed explanation, author rationale, nor the other solver's response. Mutate one captured body's options/evidence/matrix and assert the second body and frozen first response are unchanged. Assert provider-specific request keys and `v78:<contract>` cache namespace differ from V77 and from each other; a seeded V77 cache entry must never answer a V78 request.

4. **Audit both post-blind matrices.** Return distinct Luna/Gemini matrices, with different clause splits but exact option coverage. Ensure explanation-support is not dispatched until both are frozen and receives both matrices with solver identity and candidate/content hashes. Try one matrix only, the same solver twice, swapped solver IDs, wrong hash, omitted option, and stale cached matrix; each must fail closed. Require exactly four audited options per solver and complete clause coverage.

5. **Bind whitespace variants to real provenance.** For an excerpt split across PDF line wrapping, a whitespace-only premise change should bind; changed negation, punctuation, number, or word order must not. Reject substring traps such as `net` inside `internet`. Verify excerpt IDs/quotes/source IDs/locators and offsets all match the trusted registry catalog; do not allow a caller-supplied catalog or premise origin to substitute a different source with similar text. Run the same cases through blind matrix validation and explanation audit.

6. **Tighten source-silence provenance.** Current `validatePremiseBindingsV78` accepts `basis:'source_silence'` with a nonempty row `evidence_ids` list even when every premise origin is `stem` and none of those IDs is attached to a premise. Concrete case: an unrelated selected excerpt ID plus a stem-only premise passes the helper's source-silence branch. Require explicit selected excerpt context tied to the audited source-silence claim (or make the unresolved-origin contract state exactly how silence is bound); keep category-only and silence from proving contradiction.

7. **Keep every inherited correctness gate mandatory.** A numerically dependent item must include `numeric_solution` and `llm_boundary_cases`; a passage item must include integrity and answerability; all candidates retain source support, syllabus mapping, presentation, both blind solvers, alternatives, explanation audit, and exam-fit/preparation-value checks. Try missing adapter, missing key, explanation contradicting the supported answer, one plausible unresolved distractor, and disabled numeric/passsage adapter; each must quarantine. The selected key needs every clause supported, while each nonselected full option needs decisive contradiction.

8. **No V7.8 release by version selection.** With only the existing V6.2 release manifest, `factoryCalibrationReady(..., 'cuet-fit-validator-v7.8-local-draft')` and publication eligibility must remain false. V77/V6.2 release rows, local tests, hashes, and the incomplete prior study are not V7.8 release evidence. A complete fresh qualification and exact contract/prompt/effort/source binding are required before a V78 profile can be selectable.

9. **Existing controller/manual paths stay closed to V7.8.** `focusedFactory.mjs` still imports the legacy factory core/verifier (`luna-gemini-cuET-v6.2`); do not silently route generation/publication through V78. Current manual production cohort publication still requires explicit production approval, current publication evidence, current-inventory inspection, complete receipts/accounting, and authorized admin checks. The V78 local verifier must not itself set `publication_eligible`, enable a controller, or bypass those checks.
