# Rival research: chapter taxonomy, flashcards, analytics, retention (31 Oct 2026)

Method: WebSearch + WebFetch only. Vendor pages are self-reported marketing. "UNVERIFIED" = could not confirm.

## 1. Findings by platform

### CUET platforms
**Physics Wallah (PW CUET)** - https://www.pw.live/cuet/test-series , https://www.pw.live/cuet/exams/cuet-syllabus
- Test series are per subject, grouped Science / Commerce / Arts / Common (GAT, English, Hindi). Each series = mix of full mocks + chapter tests (science/humanities) or UNIT tests (commerce, e.g. Economics: 20 unit tests, 5 full, 2 PYP; Physics: 5 full, 18 chapter, 5 PYQ). Unlimited re-attempts; first test free.
- Reports: overall progress + subject, chapter, topic-wise performance (self-reported).
- Syllabus page: "based entirely on Class 12 NCERT". Structure is mixed by subject: UNITS for Accountancy (3), Business Studies (2 units/13 ch), Political Science (2), Geography (2 units x 5 ch), Biology (5 units), Economics (3 "courses": Micro, Macro, Indian Economic Development); CHAPTERS for Physics (10), Chemistry (16), History (15), Psychology (9), Sociology (10).
- Printed PW CUET Physics book has "14 Mind Maps (Revision Sheets)" at the start of each chapter (key notes, formulas) - https://oxfordbookstore.com/products/pw-cuet-ug-physics-2025-26 (via search summary).
- Notes are not clearly in the app test series; sold as books / batch materials.

**Testbook CUET** - https://testbook.com/cuet/test-series
- 739 tests: Chapter Test (259), Unit Test (125), NCERT Exemplar (37), Question Type Test (74), Full (142), CUET-pattern full session (5), Memory-based (21), PYP (76); 43 free. Subject filter.
- Post-test analysis + "personal recommendations based on strong and weak areas"; page does not describe a per-topic report in detail. Study notes + 24x7 AI doubt only in app (Testbook Pass). No dedicated revision tool described.
- Interesting: "Question Type Test" and "NCERT Exemplar" tests as separate axes.

**Easetolearn** (small rival) - https://easetolearn.com/validity/cuet-ug?pack=PRO : "Gap Fixer Sessions" drawn randomly from a PYQ-rich pool, subject/topic/chapter-wise, "to identify knowledge gaps"; max 6 mocks/day (self-reported). Closest CUET rival to a weak-chapter loop.
**Career Launcher / TestCoach / Drishti / SciAstra** - chapter tests (10+/subject), drill-down analysis, Chapter-wise Practice Papers/Tests (Drishti). Thin detail.
**Vedantu** - only crash-course + mock pages found; no mind maps / chapter-wise tests confirmed.
**Unacademy, Adda247, Toprankers, Oliveboard, Aakash/Allen digital, Magoosh** - UNVERIFIED: search surfaced nothing usable. Adda247 appears only as mock-pack seller.
**Careers360 CUET** - chapter/topic weightage articles exist (https://university.careers360.com/articles/cuet-important-topics, fetch redirected; not read). UNVERIFIED detail.

### Embibe (knowledge graph + behaviour) - https://www.embibe.com/in-en/artificial-intelligence-ai-in-education/effects-of-student-behaviour-on-learning-outcomes/
- "Concept Mastery" per concept via Bayesian Knowledge Tracing from videos, practice, tests, feedback review. Score Quotient = Academic + Behavioural + Test-taking axes (Embibe claims academic ~61% / behaviour ~39% of score impact, 94% accuracy - self-reported).
- Behavioural "Sincerity Score" from accuracy, attempt %, time %; sorts each test into 10 named behaviours (In Control, Marathoner, Trying Hard, Getting There, Slow, Train Harder, Overconfident, Low Confidence, Jumping Around, Careless). 
- "Achieve": diagnostic test -> stepwise journey of learn/practice -> reassess. https://www.embibe.com/in-en/best-education-content/deep-knowledge-tracing-to-help-students-achieve/
- Concepts auto-tagged to questions/chapters via text classification (2016 Inc42 piece; old).

### Adjacent exam apps

### Memory tools
**FSRS vs SM-2** - https://docs.ankiweb.net/faqs/what-spaced-repetition-algorithm : per-card Retrievability (recall chance now), Stability (days until R=90%), Difficulty. Fits parameters to review history; user sets "desired retention" (higher = more reviews). SM-2 = single ease factor. FSRS needs fewer reviews for same retention (docs); ~25% fewer at 90% in a 700M-review benchmark (secondary source; vendor blogs claim 30-50%, unverified). Handles late reviews after breaks much better (docs) - relevant for teens who skip days. Works best with optimisation on own history; for a new app use default parameters.
**Brainscape** - 1-5 confidence self-rating decides return time; colour-coded confidence. https://en.wikipedia.org/wiki/Brainscape
**Quizlet** - Learn mode adapts within session; true interval scheduling only in paid "Long-Term Learning"; Magic Notes = AI notes->flashcards (sources mixed). 
**RemNote** - cards written inline in notes (:: / >> markup), FSRS or SM-2, hierarchical notes. https://www.remnote.com/feature/ultimate-spaced-repetition
**Duolingo** - Half-Life Regression: per-word memory half-life; correct lengthens, mistakes shorten; skill meters = average of word strengths; "weakest words" sessions pick lowest predicted recall. A/B: +9.5% daily retention for practice sessions, +12% overall activity (Duolingo blog https://blog.duolingo.com/how-we-learn-how-you-learn). Current UI of Practice/strength meters may have been discontinued (community wiki) - UNVERIFIED.

### International
**Khan Academy mastery** - skill levels Attempted > Familiar > Proficient > Mastered (older: + Not started). Familiar at 70-85% on exercise; Proficient needs all-correct from Familiar; Mastered needs all-correct on unit test/course challenge. Course mastery % = share of skills at Proficient+Mastered. Mastery points 50/80/100. Rules changed in "Reimagined"; check current. https://support.khanacademy.org/hc/en-us/articles/115002552631
**UWorld** - performance by subject / system / (new) category; percentile vs other users. **AMBOSS** - gap finding + prioritised recommendations, peer comparison, questions linked back to library. Details from secondary sources; weak.

## 2. Class 11 / unit pattern for CUET (answer)
- Official domain-subject scope is Class 12 NCERT only (PW syllabus page; several secondary sources). Class 11 appears only as a study tip ("read 11+12" in prep advice). No CUET platform found that shows Class 11 as separate chapters in its CUET tests. (NEET apps do, because NEET is 11+12.)
- Rivals follow NCERT Class 12 chapters for science/humanities and NTA UNITS for commerce-style subjects (Accountancy, BST, Economics); test labels reflect this ("Chapter Test" vs "Unit Test").
- General Test / English have no NCERT chapters: PW lists topic areas (GK, Current Affairs, GMA, Numerical Ability, Quantitative Reasoning, Logical/Analytical Reasoning). Rivals test these as sectionals / question-types, not chapters.

## 3. Synthesis

### Ranked ideas for MockMob
1. **Chapter strength = a simple 4-level mastery state per chapter (Untouched / Learning / Solid / Mastered), not a raw %** - Khan Academy. Teens read levels faster than numbers; roll up to unit and subject "% Solid+". Thresholds need minimum attempts (e.g. n>=8 questions) to avoid noise.
2. **Weak-chapter "Fix it" session from the central bank** - Easetolearn Gap Fixer, Duolingo weakest-words, AMBOSS gap-finding. One button on the result screen and home: 15 Qs from the 2-3 weakest chapters, mixed with 30% from recently-strong ones.
3. **FSRS-style scheduler for flashcards, defaults only** - Anki/FSRS. Store stability/difficulty/last-review per card; schedule by desired retention (default 90%). Handles skipped days. Use open FSRS defaults; no per-user optimiser at launch.
4. **Two-tap card rating with 3 buttons (Missed / Got it / Easy), optional 1-5 later** - Brainscape / Anki. Keep friction low for 16-year-olds new to flashcards.
5. **Chapter flashcard deck = Key terms + Definitions + "Important NCERT lines" as typed cards** (term/definition, fill-the-blank, true/false) - NEET NCERT-line-by-line apps (PW Punch, MemoNeet microtopics). Cloze/fill-up cards on actual NCERT sentences are the proven format. Mind-map as a one-screen chapter summary (PW book mind maps / revision sheets).
6. **Tie questions to flashcards** - AMBOSS (questions link back to content), RemNote (notes become cards). Wrong answer -> "add these 2 cards to today's revision" with a tap. Closes the loop between mock and memory.
7. **Behaviour read-out after each mock, 4-5 plain-language labels** - Embibe Sincerity Score. Compute from accuracy, attempt %, time %: e.g. Careless / Rushing / Too slow / Guessing / In control. Teens new to CBT mostly lose marks on time and skips, not knowledge.
8. **Unit grouping that mirrors NTA/NCERT per subject, one level above chapter** - PW syllabus/Testbook unit tests. Chapters (Class 12 only) grouped into NTA units where NTA has units; where NTA lists only chapters (Physics, Psychology, Sociology), group into 2-4 editorial "themes" and label them as ours.
9. **Peer percentile per subject, not per chapter** - UWorld. Chapter sample sizes are too small; show "top X% of MockMob students" once enough users exist; hide otherwise.
10. **Daily revision queue with a cap (e.g. 20 cards, ~5 min) + streak on revising, not on opening** - Duolingo retention effect (+9.5% practice-session retention in A/B test) - FSRS due list is the queue.
11. **Chapter heat-strip on the analytics page: subject > unit > chapter, colour by mastery level** - UWorld subject/system/category drill-down, Embibe concept mastery. One screen, drill down one level at a time.
12. **Chapter-weight "importance" badge from PYQ frequency** - Careers360 / PW "do-or-die topics" pages; MARKS "important" idea (unverified). Only if you have PYQ counts; label "appeared in N papers" (truthful, evidence-based).
13. **Diagnostic first** - Embibe Achieve: 10-15 Q diagnostic per subject to seed chapter states, so a fresh account is not empty (matches your complete-fresh-account rule).
14. **Memory-based / question-type tests as extra axes** - Testbook (Question Type, NCERT Exemplar). Low priority; later.
15. **Confidence-before-reveal on a few Qs** (Brainscape idea) to catch Overconfident students (Embibe label) - later.

### 5 things to avoid
1. Raw "accuracy %" per chapter on 3-5 questions: noisy, demoralising. Gate by minimum attempts.
2. Embibe-style 10-label behaviour taxonomy and "Score Quotient" black boxes; unverifiable accuracy claims (94%). Keep 4-5 labels, explainable.
3. Copy-pasting competitor claim numbers (test counts, "X% better" stats). Most are self-reported; MockMob's USP is unlimited mocks - do not match their vague counts.
4. Class 11 chapters in the CUET taxonomy: scope is Class 12 NCERT only; adding Class 11 contradicts the official syllabus and bloats the app. At most an optional "prerequisite" hint per chapter.
5. Per-user FSRS parameter optimisation, Bayesian knowledge tracing and a full knowledge graph at launch: heavy, needs data you do not have. Also avoid Quizlet-style paywalled spaced repetition and hiding analysis behind a pass (Testbook locks analysis after pass expiry).

### Open questions / unverified
- Unacademy, Adda247, Toprankers, Oliveboard, Aakash/Allen digital, Magoosh: no usable evidence found.
- MARKS "important" tag, tracker and analytics: not confirmed on official page.
- Testbook / PW per-chapter report UI: only described in marketing text.
- Duolingo current Practice/strength UI: possibly discontinued.
- Khan Academy thresholds: from older support article; Reimagined differs.
- NTA's current-year unit lists per subject must be checked against NTA portal (PW itself says 2027 syllabus not yet released; PW's Accountancy unit numbering looked incomplete).
