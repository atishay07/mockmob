## 0. Decisions (CTO, this port)

1. **Navigation stays exactly as it is.** No new tab, no new dock slot, the Practice doors keep their order
   (Practise | Your papers | Learn). Learn v2 replaces the content of the Learn door; every other screen is a root page
   pushed over the shell (no dock), like Key cards today.
2. **Server switch.** The app shows Learn v2 when `GET /api/learn/subject` answers; `404 LEARN_OFF` keeps the legacy
   Learn door and the legacy Key cards screens. The last answer is kept on the phone so the door never flashes between the
   two. The demo build is always on.
3. **Data.** Production: `HttpLearnApi` over the same `/api/learn/*` routes as the web (bearer auth, the app's `ApiClient`).
   Tests and goldens: recorded fixtures (`test/fixtures/learn2/`). Emulator walk: the demo build talks to the web dev
   preview's real engine through a debug-only client (`test/device_demo/demo_learn.dart`, never compiled into the real app):
   `http://localhost:3451/preview/arena/realdeck?_to=/api/learn/...&_plan=pro|free&_student=commerce|new&_s=<name>` with
   `adb reverse tcp:3451 tcp:3451`. Nothing is deployed, pushed or written to production.
4. **Ways in (no slots).** (a) Learn door = Learn home. (b) A "Chapter feeds" row ("Key cards and questions, one at a
   time.") in Practise's More ways in, above "Untimed questions", opens the Explore page (covers, then the questions link).
   (c) Learn home's suggestions start runs and feeds. (d) Start sheet: one row "Learn a chapter". (e) Review's chapter rows
   and "The line you needed" lead to the chapter page. (f) Legacy `/cards` routes redirect into v2 when it is on.
5. **Must-know is not printed on feed and run cards** (LK13; every card there is Must-know). It stays in the Cards view,
   its filter and Find. Also fix `KcKindLine` so Must-know is a volt **word**, no box (A7 T23), and regenerate the Key cards
   goldens that change.
6. **Haptics (the app's grammar wins over the web's buzz):** a turn `light()`; a right answer `confirm()` after the server
   graded it; a wrong answer nothing (shake only); Keep `confirm()` after the 200; Got it and Easy `confirm()` after the
   acknowledgement; Missed `tick()`; option tap `tick()`; pager move nothing.
7. **Motion.** One curve for the pager, the flip and the end fan: `Motion.drawer` (= `Cubic(0.32, 0.72, 0, 1)`). Pager
   320 ms. Turn 340 ms. Reduced motion (`Motion.reduced(context)`): instant page switch with a 120 ms cross-fade, no flip
   (cross-fade), no shake, no flight. The motion guard holds: no bare `AnimatedSwitcher(`, no `Curves.ease*` outside
   `lib/core/motion` (use `MmOverlapSwitcher`, `MmSizeEase`, `Motion.*`).
8. **Watermarked print sheet (LK6)** is out of this build's first pass (the web has it; the app needs a PDF dependency).
   The chapter shelf's "Print sheet" row opens the Must-know cards view until then, and the report says so.
