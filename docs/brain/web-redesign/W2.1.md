# W2.1 Tokens, type and theme (web)

14 October 2026. Package W2.1 of `WEB-REDESIGN-PLAN-2026-10-14.md` (sections 8 to 11). Branch `web/W2.1`, cut from `feat/web-redesign`. Owner defaults accepted: D5 (Night default for the signed-in product, Light as the option, Bricolage Grotesque plus Hanken Grotesk), D6 (glass on chrome only, light as environment only, warm Night neutrals), D7 (screenshots and owner OK before a visible UI is replaced), D9, D10, logo B final. Nothing here is deployed.

## Job

Give every web surface one brand source that matches the app's Night Sheet, so the later packages (W2.2 public pages, W2.3 account and auth, W2.4 product pages) restyle by using tokens and shared components instead of inventing colours, type and states page by page.

## Outcome

1. `shared/tokens.json` is the single source: Night and Daylight colour roles, the volt accent, shadows, type roles, spacing, radii, targets, motion and glass. Values are copied from `flutter_app/lib/core/theme` (read only). `shared/build-tokens.mjs` generates `shared/tokens.css`; a unit test fails when the CSS is stale or a text role drops under 4.5:1. The Dart side stays an app-lane job.
2. Type: Bricolage Grotesque (variable: weight, `wdth` 75 to 100, `opsz` 12 to 96, checked in `next/font`'s font data) for display and numbers; Hanken Grotesk for reading. Gabarito and Geist Mono are no longer loaded. `--font-mono` now resolves to Hanken with tabular figures, so mono "label costume" is gone everywhere at once.
3. Theme: a saved choice (`mm:theme:v1`) always wins. Without one, the signed-in product (its routes, or any page for a visitor whose hint says member) opens in Night; a stranger on a marketing page opens in Light. One boot script sets `data-theme` before first paint; nothing flashes.
4. Glass: blur only on chrome (header, topbar, dock, sheets, dialogs) through `.ui-chrome`/`.ui-sheet` and the existing nav classes. `data-glass` is `full` (live blur), `lite` (dense tint plus edge light, no blur) or `off` (solid). Default: `full` on a fine pointer, `lite` on touch screens (budget Android). `prefers-reduced-transparency: reduce` and `prefers-contrast: more` force solid. Content cards are never glass: the legacy `.glass` class is now a solid raised surface.
5. Components in `src/components/ui`: Button (primary, secondary, quiet; rest, hover, focus, pressed, disabled with reason, loading that keeps label and width), Field and Input, Select, Textarea (empty, filled, focus, invalid, valid, disabled), Chip (bubble selection, pressed, disabled), Surface (plain, raised, sunken, focal: a real hierarchy instead of boxes everywhere), PageHead (no eyebrow), EmptyState, ErrorState, OfflineState, LoadingState and skeletons.
6. No eyebrows and no trailing arrows at the component level: `.eyebrow`, `.mono-label`, `.pill` and `.nav-link` lose caps, tracking, mono and the glowing dot; `Button` drops a trailing arrow or chevron icon; `Badge isEyebrow` and `EmptyState eyebrow` render nothing extra.

## Data truth

No data changes. States are presentational: loading never claims progress, errors keep the user's work and name a recovery action, empty states say what to do next.

## States

Every control above has its full state set (section 5). Theme: saved light, saved dark, no choice on a product route, no choice as a member on a marketing page, no choice as a stranger, storage blocked (falls back to the route rule, never throws). Glass: full, lite, off, reduced transparency.

## Persistence

`mm:theme:v1` (`light` | `dark`) and `mm:glass:v1` (`full` | `lite` | `off`), read in a try/catch. The Appearance setting UI for glass belongs to W2.3 (profile); it writes `GLASS_KEY` from `shared/theme.mjs`.

## Feel

Calm, warm late-night desk. One volt light per screen. Motion uses the app's curves and durations; press about 100 ms, state change 150 to 220 ms; transform and opacity only; reduced motion removes travel.

## Conflicts settled

- Warm Night neutrals (`#12110E`) instead of the standards' neutral `#181818`: the owner's newer "ice cold" note and the accepted D6 win. Not a "tinted near-black" slop item.
- The app's exit curve is an ease-in shape; on the web it is used only for exits that leave the screen (sheets closing), never for anything entering.
- The Flutter `ink3` value (`#A09989`) is used rather than the brief's `#8E877A`; the code is newer and is checked at 4.5:1 here.

## How it was built (for the packages that follow)

- Tokens: edit `shared/tokens.json`, run `node shared/build-tokens.mjs`, commit both. `node --test shared/tests/*.test.mjs` checks the CSS is current, the Night Sheet anchors match the app, text roles hold 4.5:1, and the theme rules. Web-only additions not in the app: `voltWash`, `hover`, the `pop` shadow and the fluid `webMax` type sizes.
- Variables: fixed palettes `--mm-night-*` and `--mm-day-*`; theme roles `--mm-ground`, `--mm-ink-2`, `--mm-accent-text` and so on (follow `data-theme`; `.mm-night` and `.mm-day` pin a subtree); type `--mm-type-<role>-size|line|weight|tracking` and `.type-<role>` classes; `--mm-space-*`, `--mm-radius-*`, `--mm-ease-*`, `--mm-dur-*`. Tailwind utilities: `bg-mm-raised`, `text-mm-ink-2`, `border-mm-line` and the rest of `--color-mm-*`.
- The older variable layers now read the tokens, so every existing page repaints without a rewrite: `--a-*` (product, arena.css), `.mm` `--paper`/`--ink` (marketing, globals.css and marketing-theme.css), and the root legacy dialect (`--ink`, `--text-*`), which stays Night.
- Buttons: `.btn-volt`, `.btn-outline`, `.btn-ghost` and `.mm-btn--primary|secondary|quiet|onnight` are aliases of the kit's primary, secondary and quiet buttons, defined once in `src/components/ui/ui.css` inside Tailwind's `components` layer (utilities and page rules still win).
- `.eyebrow` renders nothing anywhere (as it already did inside `.mm`); `.mono-label`, `.pill`, `.nav-link` are sentence case without tracking; `--font-mono` is Hanken.
- `.glass` is a solid raised surface. Live blur exists only in the chrome list in `ui.css`.
- Development check page: `/preview/ui-kit` (404 in production) shows type, colour roles, every button, field, chip, surface and state, and a glass sheet, with Night/Light and Full/Lite/Off switches that do not save.
